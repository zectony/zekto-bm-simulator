01 · Entry-Barrier-Weighted Priority

진입장벽을 고려한 시장침투 우선순위

위챗페이 결제 도입 관점의 진입장벽 × 수익성 4단계 분류 — 기존 결제단말·POS 교체 저항, 외국인 결제수요, 기존 결제대행사 선점 여부가 기준

· 1차 진입(저장벽·고수익): 중국인 등 외국인 결제수요가 이미 높은 업종. POS 교체 없이 결제단말만 추가하면 되는 소규모 매장 위주라 영업·설치 저항이 낮음
· 2차(저장벽·저수익): 영업은 쉬우나 건당 결제금액이 작아(즉석사진 5천원대 등) 위챗페이 결제 총액 자체가 작음
· 3차(중장벽): 개인 매장은 진입장벽이 낮지만, 프랜차이즈 본사가 이미 다른 결제대행사와 전속 계약을 맺고 있는 경우가 많아 개별 영업이 필요
· 장기과제(고장벽): 편의점은 본사 차원의 결제 계약이 이미 확정돼 있어 개별 매장 영업이 불가능. 의료기관(피부과·성형외과·내과)은 병원 전용 결제·수납 시스템이 따로 있어 일반 POS 결제단말 추가가 구조적으로 어렵고, 대형 병원은 이미 전담 결제대행사(VAN사)와 계약돼 있는 경우가 많음
1차 진입 2차 3차 장기과제

02 · Revenue Simulation

Zekto 예상수익 비교 · 필터

13개 카테고리 합계 (대형쇼핑몰·백화점·면세점 제외)

① 매장 전체 외국인매출(시장 규모) = 계약 매장수 × 매장당(또는 건당) 매출 × 연간 배수(월매출은 ×12, 팝업스토어는 건당 총매출이라 ×1). Zekto 이용 여부와 무관한 전체 시장 크기다.

② Zekto 유통액(GMV) = ①× 위챗페이 결제 도입률. 매장의 외국인 고객 전체가 위챗페이로 결제하는 게 아니라, 등록 후에도 그중 일부만 실제로 위챗페이를 선택하기 때문에 이 비율을 곱해야 실제 위챗 결제 유통액이 나온다.

③ Zekto 예상수익 = ②× 위챗 가맹수수료. 매장 전체 외국인 매출이 아니라, 실제로 위챗페이로 결제된 금액에만 수수료가 발생한다.

"현재 시장 규모" 카드는 13개 카테고리 ①(전체 외국인매출)의 합계, "Zekto 총 예상수익"은 13개 카테고리의 ③ 합계다. 지금 필터로 선택 중인 카테고리는 슬라이더 실시간 값을, 나머지 12개는 각 카테고리의 기본 가정값(사전 조사 근거 기반)을 사용해 합산한다.

대형쇼핑몰·백화점·면세점은 내부에 다양한 브랜드·카테고리가 혼재돼 가맹점 단위로 명확히 나눌 수 없어 분석 범위에서 제외했다(1.2 우선순위 판단 참고).

05 · Field Validation Plan

오프라인 검증 계획

우선순위·기간·성공기준(공통)

P1가맹점 결제단말 현황 실측 (3대 상권: 강남·중구·마포)2주
Pass 기준: 실측 매장수가 시뮬레이터 가정치의 ±30% 이내이며, 기존 POS와 위챗페이 단말 병행 설치가 가능한 매장 비중을 함께 확인. 벗어나면 슬라이더 기본값을 실측치로 교체 후 재계산
P1도입 의향·기존 결제대행사 계약현황 인터뷰 (10~20곳)3주
Pass 기준: 응답 매장의 70% 이상이 위챗페이 등록 의향 표명 + 기존 결제대행사와 전속계약이 없는 매장 비중 확인 + 가맹점당 월 위챗 결제 추정액 응답으로 95% 신뢰구간 산출 가능한 표본 확보
P1 두 항목 모두 Pass → P2 진행
P2소규모 파일럿 등록·결제전환 테스트 (5~10개 매장)6주
Pass 기준: 등록 후 실제 위챗페이 결제가 발생한 매장 비율(활성화율) 50% 이상, 매장당 월 결제건수가 사전 추정치의 70% 이상. 표본 부족 시 Conditional Pass로 표본 확대 후 재판정
P2현장 설치·정산 프로세스 테스트 (5~10개 매장)4주
Pass 기준: 단말 설치부터 결제 활성화까지 평균 소요일 7일 이내, 정산 오류·분쟁 발생률 5% 이하
P2 Pass → 카테고리 확정 및 정식 영업 전환
P3경쟁 결제대행사(VAN사·PG사) 수수료 벤치마크2주
Pass 기준: Zekto 가정 위챗 가맹수수료가 시장 평균 대비 ±3%p 이내 — 벗어나면 수수료율 슬라이더 기본값 재설정
P1·P2는 순차 진행(게이트 통과 후 다음 단계), P3는 병행 가능. 모든 Pass/Fail 판정은 표본크기·기간·비교 대조군 구성을 함께 기록해 사후 재현 가능하도록 관리한다.
